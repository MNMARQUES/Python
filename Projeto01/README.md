# Projeto Python — Fundamentos de Desenvolvimento e Manipulação de Dados

## Objetivo do Projeto

O projeto teve como objetivo consolidar os fundamentos da linguagem Python por meio da resolução de problemas práticos, aplicando conceitos essenciais de programação, manipulação de estruturas de dados, criação de funções e organização de código reutilizável.

As atividades foram desenvolvidas para demonstrar como Python pode ser utilizado na automatização de tarefas, no processamento de informações e na construção de soluções simples e eficientes para problemas do cotidiano.

## Ferramentas e Tecnologias Utilizadas

- **Python:** linguagem de programação utilizada para desenvolver e executar as soluções.
- **Google Colab:** ambiente de desenvolvimento em nuvem utilizado para escrever, executar e validar os códigos.
- **Estruturas de dados:** listas, dicionários e conjuntos para armazenar, organizar e processar informações.
- **Funções e expressões lambda:** utilizadas para modularizar operações, reutilizar código e realizar cálculos.
- **Módulos Python:** empregados na organização de funções em arquivos independentes, permitindo sua importação e reutilização.
- **Manipulação de dados:** utilização de recursos nativos da linguagem, como `len()`, `max()`, `min()` e operações com conjuntos.

## Atividades Desenvolvidas

1. **Manipulação de dicionários:** processamento de uma lista de nomes para calcular e armazenar a quantidade de caracteres de cada nome.
2. **Dict comprehension:** simplificação da criação de dicionários por meio de expressões concisas e eficientes.
3. **Desenvolvimento de funções:** implementação de uma função para calcular a área de um círculo, utilizando argumentos padrão e parâmetros personalizados.
4. **Funções lambda:** aplicação de funções anônimas para realizar cálculos de maneira compacta.
5. **Modularização do código:** criação do módulo `processalista.py`, com funções para identificar o maior e o menor número ímpar de uma lista e reutilizar essas operações.
6. **Operações com conjuntos:** desenvolvimento de funções para identificar dias de disponibilidade simultânea entre dois ou três especialistas de uma clínica, automatizando a análise de agendas.

## Resultados Obtidos

Todas as atividades foram executadas e validadas corretamente, permitindo aplicar na prática os conceitos estudados. O projeto demonstrou a importância da organização do código, da reutilização de funções e da escolha adequada das estruturas de dados para simplificar a resolução de problemas.

Além disso, a atividade de disponibilidade médica apresentou uma aplicação prática de lógica computacional, utilizando operações de interseção entre conjuntos para identificar automaticamente os dias compatíveis com as agendas dos profissionais.

## Conclusão

A realização deste desafio fortaleceu os conhecimentos fundamentais de Python e contribuiu para o desenvolvimento do raciocínio lógico, da capacidade de decompor problemas e da criação de soluções modulares e reutilizáveis.

Esses fundamentos constituem uma base importante para avançar em projetos de automação, engenharia de dados, análise de dados e inteligência artificial, áreas nas quais Python desempenha um papel relevante.

**Competências praticadas:** Python, lógica de programação, estruturas de dados, funções, modularização, manipulação de dados e resolução de problemas.
